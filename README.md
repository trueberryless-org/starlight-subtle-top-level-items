# Starlight Subtle Top-Level Items

[![Built with Starlight](https://astro.badg.es/v2/built-with-starlight/tiny.svg)](https://starlight.astro.build)
[![Netlify Status](https://api.netlify.com/api/v1/badges/5589be3d-3bec-41a6-a8c5-b9bfb73ed0d8/deploy-status)](https://app.netlify.com/sites/starlight-subtle-top-level-items/deploys)

Example [Starlight](https://starlight.astro.build) website for subtle styling of top-level items in the sidebar. It compares three styles side by side, each as its own topic built with [starlight-sidebar-topics](https://github.com/HiDeoo/starlight-sidebar-topics).

## Development

```sh
pnpm install
pnpm dev
```

| Command         | Action                                |
| --------------- | ------------------------------------- |
| `pnpm dev`      | Start the local development server    |
| `pnpm build`    | Build the site to `./dist/`           |
| `pnpm check`    | Type check the project                |
| `pnpm lint`     | Lint with oxlint                      |
| `pnpm knip`     | Find unused files and dependencies    |
| `pnpm test`     | Run the unit tests                    |
| `pnpm test:e2e` | Run the end-to-end tests (Playwright) |
